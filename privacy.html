隐私说明

更新于 2026 年 11 月

这是一个个人网站，用来放研究项目、获奖记录和旅行轨迹。下面说明它会接触到的数据处理方式。

访问数据

本站没有安装任何统计脚本，没有 cookie，也不做用户画像。页面托管在 GitHub Pages 上，服务器会按常规记录访问日志，例如 IP 地址和请求时间，这部分由 GitHub 按其隐私政策处理。

第三方请求

页面的字体从 Google Fonts 加载，样式本身存放在本站。加载字体时，你的浏览器会把 IP 地址发给 Google，这是使用该字体服务的必要过程。如果你希望避免这次请求，可以使用浏览器的内容拦截功能。

邮件

如果你通过页面上的邮箱地址写信给我，我会保留这封邮件以便回复。邮件内容不会用于其他用途，也不会转给第三方。

外链

站点会链接到 GitHub 等外部网站，那些网站的数据处理方式由各自的政策决定。

联系
